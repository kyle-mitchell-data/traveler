        What's going on here

        There is no fixed server

        The site is one AWS Lambda function, and only one copy of it exists between moves. It has no home region. Wait five minutes and it runs somewhere else.

        It moves itself

        No pipeline or person deploys it. Every three to five minutes the running copy picks a region, builds a copy of itself there from its own code, switches traffic, and the new copy deletes the old one. The code carries itself around the world.

        Visitors don't notice

        There is one address. CloudFront looks up where the traveler is on every request. The old copy keeps answering until every edge location has switched, so a move doesn't drop requests. In testing: zero failed requests across 20 moves and about 2,800 probes.

        It fails safe

        If any step of a move fails, the move is cancelled and the traveler stays put. A watchdog checks every five minutes and brings it back if it stops. There are never more than two copies.
