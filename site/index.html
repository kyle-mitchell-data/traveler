How it works

The server behind this page is a single AWS Lambda function, and only one copy exists at a time. It stays in a region for three to five minutes, then moves itself to another one.

To move, the running copy builds a new copy of itself in the destination, checks that it's healthy, and points the edge at it. It keeps serving until edge locations worldwide have picked up the change, then hands over. The new copy retires the old one. If any step fails, the move is cancelled and the traveler stays where it is.

You always visit the same address. CloudFront looks up where the traveler is on every request and sends you there, so the server moves and the visitor never notices.

While it stays somewhere, it posts what it notices about the place: local time, weather, earthquakes, holidays and history, from public sources it credits and links.
